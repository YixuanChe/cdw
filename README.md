# cdw

Detail page behind the QR code on the CEEPC Industry Night 2026 poster
(Yixuan Che, Monash University). Served by GitHub Pages at
<https://yixuanche.github.io/cdw/>.

One page, `index.html`, with its pictures in `img/` and a contact card (`yixuan-che.vcf`).
No build step. Edit, commit, push; Pages updates in about a minute.

The URL is printed on the poster as a QR code, so keep this repository public,
keep Pages enabled, and do not rename the repository.
